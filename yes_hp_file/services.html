事業内容

株式会社YESは、DX戦略からIT開発、AI活用、クラウド運用まで、企業の変革に必要な機能を横断的に提供します。

01

DXコンサルティング

経営・現場・システムの間にあるズレを可視化し、実現可能なDXロードマップに落とし込みます。

  • 業務フロー可視化
  • 課題抽出・優先順位設計
  • システム化構想
  • 導入計画・KPI設計
02

IT・システム開発

現場で使われることを前提に、Webアプリ・管理画面・業務システム・API連携を設計開発します。

  • Webアプリ開発
  • 業務システム開発
  • 予約・受発注・CRM
  • API / 外部サービス連携
03

AI・データ活用

生成AIやデータ分析を業務に組み込み、検索、要約、自動化、分析、レポート作成を効率化します。

  • 生成AI導入
  • 社内データ検索
  • ダッシュボード構築
  • レポート自動化
04

クラウド・運用改善

クラウド基盤、セキュリティ、保守体制、運用ルールを整え、開発後も継続改善できる状態を作ります。

  • AWS / GCP / Firebase
  • 監視・バックアップ
  • 権限管理
  • 保守運用設計
